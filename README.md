# Agenda de Citas (CRUD Next.js)

Aplicación web desarrollada para la gestión y administración de citas, permitiendo crear, consultar, editar y eliminar registros de manera rápida e intuitiva.
---
## Tecnologías utilizadas
* **[Next.js](https://nextjs.org/)** - Framework de React para el desarrollo web.
* **React** - Biblioteca para la construcción de interfaces de usuario.
* **Tailwind CSS** - Framework de estilos para un diseño moderno y responsivo.
